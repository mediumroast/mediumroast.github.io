# mediumroast.github.io

Source for https://mediumroast.github.io — the Mediumroast open source
projects page, published from `docs/` via GitHub Pages.

`docs/index.html` and `docs/style.css` are hand-authored static files. There
is no build step and no site generator — edit them directly. (The site was
previously generated by the Blocs app from a `.bloc` project file; that
workflow has been retired.)
